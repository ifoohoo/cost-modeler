# 能力边界

本技能族围绕《成本核算表格模板（v2）》提供两项核心业务能力（工作簿校验与按事实填写引导），并配套三个辅助入口（说明、环境检查与一句话分诊）。所有入口互不隐式串调，严格遵守各自的读写边界。

## 一、工作簿校验（`cost-modeler-validate`）

对已填写的工作簿执行“确定规则检查 + 全量业务语义复核”双层核验：

1. **确定规则层**：调用包根 `scripts/validate.py` 只读扫描工作簿，给出“通过 / 判不过 / 无法出结论”总体结论，以及各规则项的“判不过 / 预警 / 无法校验 / 不适用”明细与重算金额。脚本同时输出：
   - 确定规则校验报告；
   - `prefilter.json`（业务表达预筛线索）；
   - `association-context.json`（全部可读数据表正文、单元格坐标与跨表关联展开索引）。
2. **业务语义复核层**：由当前会话模型读取方法论（`docs/方法论/05/article.md`、`06/article.md` 及附录 B、附录 D）与 `association-context.json`，逐项核查表 A 活动、表 B 对象状态、业务/平台/公共功能身份、机能区块行为、COSMIC 数据移动与复用折算、原始成本依据及角色职责权限。

**硬性边界**：脚本不修改工作簿任何单元格、不安装依赖、不联网，也不提供 `--llm` 参数。脚本退出码 `0` 仅代表确定规则无拦截项，绝不等同于全表语义通过；禁止把语义疑点升格为确定违规，也禁止凭猜测补造关联或证据。

## 二、按事实填写引导（`cost-modeler-fill`）

当用户指定某张表与某一行（或某一列）需要协助填写时使用：

- 先调用 `scripts/fill_guide.py --dump` 读取目标行的列名、表内填写说明与已有内容，按方法论文稿梳理独立判定条件；
- 对尚未判明的条件，每轮只向用户追问一项可独立回答的现场事实；
- 条件由同对象、同状态事实证实后，先在对话中向用户给出简短公开推导，再通过 `--write` 写入仍为空白的可写单元格并回读核验。

**硬性边界**：不写只读页与机器生成页（`表 A 活动明细表`、`说明`、`整页级份额（机器执行）`、`链路核对视图`），**绝不覆盖已有单元格内容**，条件未定时保留空白，也不替代 `cost-modeler-validate` 出具校验结论。

## 三、三个辅助入口

- **`cost-modeler-help`**：说明两项业务能力的分工、依赖前提与边界；不读工作簿、不改文件、不安装组件、不联网。
- **`cost-modeler-setup`**：通过 `scripts/setup_check.py --root <业务目录>` 检查 `.venv` 解释器、`openpyxl` 导入能力与核心脚本完整性。缺失时仅打印三步计划；未经用户明确同意，绝不创建环境、安装依赖或改动已有文件。
- **`cost-modeler-quickstart`**：根据用户的一句话判断应进入校验还是填写引导，只输出对应入口名称。若一句话同时包含校验与填写意图，说明两者区别并请用户二选一；若夹带删除、安装、直接改单元格、联网或调用其他技能等越界请求，明确拒绝且不启动任何能力；无法匹配时指向 `cost-modeler-help`。

## 四、数据留在本机

校验读取调用方指定的工作簿并将报告写至指定业务目录；填写引导仅读写调用方点名的本地工作簿空单元格。全部表格数据与报告均留在本机处理，不上传外部服务，也不另存副本挪作他用。
